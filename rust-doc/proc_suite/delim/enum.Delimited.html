Enum Delimited 

Source 
pub enum Delimited<'a, T = ()> {
    Paren(ParseBuffer<'a>),
    Brace(ParseBuffer<'a>),
    Bracket(ParseBuffer<'a>),
    _Marker(PhantomData<fn(&'a ()) -> T>),
}
Expand description

Represents the contents of a delimited group following a key.

This enum is a parsing helper, not part of the final AST. It temporarily holds the ParseBuffer corresponding to one of the supported delimiters: (), {}, or [].

The delimiter itself is consumed during parsing; only the inner token stream is retained for further parsing.

The generic parameter T can be used to enforce a specific delimiter at compile time (e.g. [Paren], [Brace], [Bracket] from syn::token).
