Expand description

Validates duplicate entries in list-like parsed arguments.

Implement this for list wrappers to detect repeated items based on a normalized string key. This check ignores spans and hygiene and compares items purely by their string representation.

Use DuplicateCheck::duplicate_check to emit a diagnostic on the first duplicate found.
