pub fn internal_code() -> Vec<Attribute>
Expand description

Returns attributes used to mark generated implementation items as internal.

These attributes hide generated implementation details from Rustdoc and suppress the dead_code diagnostic that can occur when an item exists only to support macro expansion.

The returned attributes are equivalent to:

ⓘ
#[doc(hidden)]
#[allow(dead_code)]
