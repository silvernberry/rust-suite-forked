Trait FirstDocAttribute 

Source 
pub trait FirstDocAttribute {
    // Required method
    fn first_doc_attribute(&mut self, op: &mut AttributesFirstDoc);
}
Expand description

Provides the ability to locate the first Rustdoc attribute on a syntax node.

The returned operation records the index of the first matching attribute, if one exists.

Required Methods§

Dyn Compatibility§

This trait is dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety".
