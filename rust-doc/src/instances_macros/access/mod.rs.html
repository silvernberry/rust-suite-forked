13// ```````````````````````````````` INSTANCE ACCESS ``````````````````````````````
14// ===============================================================================
15
16//! Transforms an instance-bound `impl` into standalone Rust items that expose
17//! the associated types, constants, and functions through the instance
18//! hierarchy.
19//!
20//! The transformation begins with an `impl` whose `Self` type represents an
21//! instance node. The associated items inside that `impl` can use `Self` to
22//! refer to the instance-bound types and functions.
23//!
24//! For example, an instance-node associated type's inherent
25//! implementation may contain:
26//!
27//! ```ignore
28//! impl<T: NodeBound> for T::Node
29//! where
30//!     Self: InstanceBound,
31//! {
32//!     type Value = Self::Data;
33//!
34//!     fn get() -> Self::Value {
35//!         Self::value()
36//!     }
37//! }
38//! ```
39//!
40//! The access transformation does not leave these items inside the `impl`.
41//! It validates the restricted instance-access syntax, extracts the instance
42//! information, propagates the required generics, and replaces the `Self`
43//! references with explicit instance-bound representations.
44//!
45//! A simple associated-type access such as:
46//!
47//! ```ignore
48//! Self::Value
49//! ```
50//!
51//! is transformed into an explicit instance-bound access:
52//!
53//! ```ignore
54//! <<T as NodeBound>::Node as InstanceBound>::Value
55//! ```
56//!
57//! For a leaf instance, where the instance is already known, the access is
58//! specialized to the fixed instance representation:
59//!
60//! ```ignore
61//! Self::Value
62//! ```
63//!
64//! becomes conceptually:
65//!
66//! ```ignore
67//! <<T as NodeBound>::Node as InstanceBound>::Value
68//! ```
69//!
70//! The same transformation applies to associated-function calls. For example:
71//!
72//! ```ignore
73//! Self::get()
74//! ```
75//!
76//! becomes an explicit access to the instance-bound function:
77//!
78//! ```ignore
79//! <<T as NodeBound>::Node as InstanceBound>::get()
80//! ```
81//!
82//! The original associated items are then emitted as standalone items rather
83//! than remaining inside the implementation:
84//!
85//! ```ignore
86//! impl<T: NodeBound> for T::Node
87//! where
88//!     Self: InstanceBound,
89//! {
90//!     type Value = Self::Data;
91//!
92//!     fn get() -> Self::Value {
93//!         Self::value()
94//!     }
95//! }
96//! ```
97//!
98//! becomes conceptually:
99//!
100//! ```ignore
101//! type Value<T> = <<T as NodeBound>::Node as InstanceBound>::Data;
102//!
103//! fn get<T>() -> Value<T> {
104//!     <<T as NodeBound>::Node as InstanceBound>::value()
105//! }
106//! ```
107//!
108//! The exact generated representation depends on whether the access is a leaf
109//! or non-leaf access ([`AccessArgs`]), but the important property is that the
110//! generated items no longer depend on the surrounding `impl` for their instance context.
111//!
112//! ## Validation
113//!
114//! Before transformation, the input is checked against the syntax supported by
115//! instance access. This includes the form of the impl self type, the supported
116//! forms of `Self`, associated-item qualification, associated-type
117//! dependencies, function receivers, constants, and predicates.
118//!
119//! For example, the following `Self` forms are supported:
120//!
121//! ```ignore
122//! Self
123//! Self::Item
124//! Self::Item<T>
125//! <Self as Trait>::Item
126//! <Self::Item as Trait>::Item
127//! ```
128//!
129//! Unsupported forms are rejected before replacement is attempted:
130//!
131//! ```ignore
132//! Self<T>
133//! <T as Self>::Item
134//! <T as Trait>::Self
135//! ```
136//!
137//! This keeps the later transformation passes working on syntax whose meaning
138//! is already unambiguous within the instance-access model.
139//!
140//! ## Extraction
141//!
142//! Once the input has been validated, the instance node ([`InstanceNodeBound`])
143//! and its instance bound ([`InstanceBound`]) are extracted from the implementation.
144//!
145//! For example, an implementation rooted at an instance type provides the
146//! information required to interpret:
147//!
148//! ```ignore
149//! Self::Item
150//! ```
151//!
152//! as an access to an associated item belonging to that instance rather than
153//! as an ordinary Rust associated-item lookup.
154//!
155//! The extracted information is then used by the subsequent replacement
156//! passes, so those passes do not need to rediscover the instance hierarchy
157//! from the original syntax.
158//!
159//! ## Generic propagation
160//!
161//! Because associated items are eventually emitted as standalone items, generic
162//! parameters that originally belonged to the `impl` must be made available to
163//! those generated items.
164//!
165//! ## Leaf access
166//!
167//! Leaf access is used when the requested instance is already known.
168//! Consequently, the transformation can directly specialize the instance
169//! representation.
170//!
171//! For example:
172//!
173//! ```ignore
174//! Self::Value
175//! ```
176//!
177//! can become:
178//!
179//! ```ignore
180//! <T::Node as InstanceBound<Concrete>>::Value
181//! ```
182//!
183//! and:
184//!
185//! ```ignore
186//! Self::get()
187//! ```
188//!
189//! can become:
190//!
191//! ```ignore
192//! <T::Node as InstanceBound<Concrete>>::get()
193//! ```
194//!
195//! No runtime instance-position lookup is required because the instance is
196//! fixed by the generated type representation.
197//!
198//! ## Non-leaf access
199//!
200//! Non-leaf access is different because the requested instance is selected at
201//! runtime. Rust does not provide dynamic selection of a trait instance in the
202//! form required by this transformation, so non-leaf access provides this
203//! ability by generating a statically known instance hierarchy and performing
204//! the selection over that hierarchy at runtime.
205//!
206//! The generated function therefore receives additional byte-string arguments
207//! containing the dynamic identifiers used to select the instance.
208//!
209//! An access such as:
210//!
211//! ```ignore
212//! Self::get(id)
213//! ```
214//!
215//! represents a runtime instance selection. The transformation starts from a
216//! known initial instance and optimistically derives the reachable trait
217//! instances as a range of statically generated positions. The runtime
218//! identifier is then used to select the corresponding position within that
219//! generated range.
220//!
221//! The hierarchy and all possible positions are generated statically. Runtime
222//! execution only determines which of those already-generated positions is
223//! selected.
224//!
225//! Conceptually, a single dynamic identifier is resolved as:
226//!
227//! ```ignore
228//! match check(id) {
229//!     Some(index) => accessor(index),
230//!     None => Error::OutOfRange,
231//! }
232//! ```
233//!
234//! When multiple dynamic identifiers are involved, each identifier selects a
235//! position at its corresponding level of the generated hierarchy:
236//!
237//! ```ignore
238//! match check(id1) {
239//!     Some(index1) => match check_next(index1, id2) {
240//!         Some(index2) => accessor(index1, index2),
241//!         None => Error::OutOfRange,
242//!     },
243//!     None => Error::OutOfRange,
244//! }
245//! ```
246//!
247//! The additional runtime cost is therefore minimized to the generated
248//! selection matches. Each dynamic identifier incurs one such selection,
249//! which the compiler can optimize into a jump table where appropriate.
250//! There is no runtime traversal of the trait hierarchy itself; the hierarchy
251//! has already been derived and materialized during code generation.
252//!
253//! The runtime cost is additionally O(D), where D is the number of dynamic identifiers.
254//! Each dynamic identifier contributes one generated selection, typically
255//! compiled as a jump table, so the runtime performs one positional dispatch
256//! per dynamic identifier.
257//!
258//! `Error::OutOfRange` represents an identifier that cannot be resolved at the
259//! required position. `Error::Exhausted` represents a resolved numeric position
260//! for which no generated accessor exists, even though the identifier itself
261//! exists.
262//!
263//! Associated-type paths in non-leaf access do not themselves contain these
264//! runtime identifiers. For example:
265//!
266//! ```ignore
267//! Self::Assoc
268//! ```
269//!
270//! is transformed into the terminal representation:
271//!
272//! ```ignore
273//! <T::Node as InstanceBound<TerminalAccess>>::Assoc
274//! ```
275//!
276//! The dynamic identifiers are introduced when the enclosing function call is
277//! transformed.
278//!
279//! ## Standalone `Self` references
280//!
281//! `Self` references that refer to the implementation itself are also replaced
282//! because the generated items no longer have an enclosing `impl` providing
283//! `Self`.
284//!
285//! For example:
286//!
287//! ```ignore
288//! fn make() -> Self {
289//!     ...
290//! }
291//! ```
292//!
293//! must become a standalone function whose return type explicitly identifies
294//! the original implementation self type.
295//!
296//! ## Documentation representation
297//!
298//! The transformation also produces a documentation representation of the
299//! generated items. The implementation is transformed separately for
300//! `cfg(doc)` and `cfg(not(doc))` so that documentation can expose the
301//! instance-access structure without requiring the runtime machinery used by
302//! non-leaf access.
303//!
304//! The executable representation therefore contains the runtime resolution
305//! required for dynamic instance access, while the documentation
306//! representation preserves the corresponding generated API structure.
307//!
308//! ## Final result
309//!
310//! The complete transformation can therefore be viewed from the user's
311//! perspective as taking an instance-bound implementation such as:
312//!
313//! ```ignore
314//! impl<T: NodeBound> T::Node {
315//!     type Value = Self::Data;
316//!
317//!     fn get(id: &[u8]) -> Self::Value {
318//!         Self::value()
319//!     }
320//! }
321//! ```
322//!
323//! and producing standalone generated items whose instance accesses are
324//! explicit:
325//!
326//! ```ignore
327//! type Value<T> =
328//!     <<T as NodeBound>::Node as InstanceBound<...>>::Data;
329//!
330//! fn get<T>(id: &[u8]) -> Value<T> {
331//!     /* generated instance resolution */
332//! }
333//! ```
334//!
335//! The implementation is no longer required after lowering. Validation
336//! establishes that the source can be represented by the instance-access
337//! model, extraction identifies the instance information, replacement lowers
338//! the `Self`-based representation into explicit generated syntax, and final
339//! confirmation verifies that the resulting standalone items satisfy the
340//! invariants of the generated representation.

389// ````````````````````````` INSTANCE ACCESS ENTRY-POINT `````````````````````````
390// ===============================================================================

392/// Performs the complete instance-access transformation on a Rust file.
393///
394/// The entry point locates the instance-bound `impl`, clones it into separate
395/// documentation and executable representations, and runs the corresponding
396/// transformation pipeline on each representation. The transformed
397/// implementation items are then converted into standalone functions,
398/// constants, and types and assigned their respective `cfg` attributes.
399///
400/// The executable representation uses [`InstanceAccessImpl`] and therefore
401/// includes the runtime machinery required for non-leaf instance selection.
402/// The documentation representation uses [`InstanceAccessImplDoc`] and
403/// preserves the documentation-facing form without that runtime machinery.
404///
405/// For example, an input containing:
406///
407/// ```ignore
408/// impl<T: NodeBound> T::Node {
409///     type Value = Self::Data;
410///
411///     fn get(id: &[u8]) -> Self::Value {
412///         Self::value()
413///     }
414/// }
415/// ```
416///
417/// is lowered into standalone items conceptually represented as:
418///
419/// ```ignore
420/// #[cfg(doc)]
421/// type Value<T> = ...;
422///
423/// #[cfg(doc)]
424/// fn get<T>(id: &[u8]) -> ... {
425///     ...
426/// }
427///
428/// #[cfg(not(doc))]
429/// type Value<T> = ...;
430///
431/// #[cfg(not(doc))]
432/// fn get<T>(id: &[u8]) -> ... {
433///     ...
434/// }
435/// ```
436///
437/// The original `impl` is removed from the file after its supported associated
438/// items have been transformed. The resulting file therefore contains only
439/// the generated standalone representation, with matching documentation and
440/// non-documentation items.
441///
442/// The final confirmation verifies that the transformation produced only the
443/// supported standalone item kinds, that every documentation item has a
444/// corresponding non-documentation item and vice versa, that each item has
445/// exactly one of the expected `cfg(doc)` or `cfg(not(doc))` attributes, and
446/// that no `impl` or unresolved `Self` remains.
447#[derive(Debug, Clone)]
448pub(crate) struct InstanceAccess;
449
450impl<'a> Transformation<File, AccessArgs> for InstanceAccess {
451    fn raw_transform(
452        &self,
453        transform: &mut File,
454        context: &AccessArgs,
455    ) -> Result<(), proc_macro2::TokenStream> {
456        let Some(impl_) = transform.items.iter().find_map(|item| {
457            if let Item::Impl(impl_) = item {
458                return Some(impl_);
459            }
460            None
461        }) else {
462            return Err(ValidBugs::ImplNotProvidedInFile {}.into());
463        };
464
465        let mut doc_impl = impl_.clone();
466        let mut not_doc_impl = impl_.clone();
467
468        InstanceAccessImpl::checked_transform(&InstanceAccessImpl, &mut not_doc_impl, context)?;
469        let mut not_doc_items = impls_to_items(not_doc_impl.items);
470        append_cfg(&mut not_doc_items, false);
471
472        InstanceAccessImplDoc::checked_transform(&InstanceAccessImplDoc, &mut doc_impl, context)?;
473        let mut doc_items = impls_to_items(doc_impl.items);
474        append_cfg(&mut doc_items, true);
475
476        *transform = File {
477            shebang: None,
478            attrs: Default::default(),
479            items: Default::default(),
480        };
481        transform.items.extend(doc_items);
482        transform.items.extend(not_doc_items);
483
484        Ok(())
485    }
486
487    fn validate_transform(
488        &self,
489        transform: &File,
490        _: Option<&AccessArgs>,
491    ) -> Result<(), proc_macro2::TokenStream> {
492        let mut doc_items = Vec::new();
493        let mut not_doc_items = Vec::new();
494
495        if transform.items.is_empty() {
496            return Err(ValidBugs::ItemNotProvidedInFile {}.into());
497        }
498
499        for item in &transform.items {
500            let (ident, attrs) = match item {
501                Item::Fn(item) => (&item.sig.ident, &item.attrs),
502                Item::Const(item) => (&item.ident, &item.attrs),
503                Item::Type(item) => (&item.ident, &item.attrs),
504
505                Item::Impl(_) => {
506                    return Err(ValidBugs::ImplProvidedInFile {}.into());
507                }
508
509                _ => {
510                    return Err(ValidBugs::InvalidItemCfg {}.into());
511                }
512            };
513
514            let mut is_doc = false;
515            let mut is_not_doc = false;
516
517            for attr in attrs {
518                if !attr.path().is_ident("cfg") {
519                    continue;
520                }
521
522                let _ = attr.parse_nested_meta(|meta| {
523                    if meta.path.is_ident("doc") {
524                        is_doc = true;
525                    } else if meta.path.is_ident("not") {
526                        meta.parse_nested_meta(|nested| {
527                            if nested.path.is_ident("doc") {
528                                is_not_doc = true;
529                            }
530
531                            Ok(())
532                        })?;
533                    }
534
535                    Ok(())
536                });
537            }
538
539            match (is_doc, is_not_doc) {
540                (true, false) => doc_items.push(ident),
541                (false, true) => not_doc_items.push(ident),
542
543                (false, false) | (true, true) => {
544                    return Err(ValidBugs::InvalidItemCfg {}.into());
545                }
546            }
547        }
548
549        for ident in &doc_items {
550            if !not_doc_items.iter().any(|other| other == ident) {
551                return Err(ValidBugs::NotDocItemNotProvided {}.into());
552            }
553        }
554
555        for ident in &not_doc_items {
556            if !doc_items.iter().any(|other| other == ident) {
557                return Err(ValidBugs::DocItemNotProvided {}.into());
558            }
559        }
560
561        struct Visitor {
562            found: bool,
563        }
564
565        impl Visit<'_> for Visitor {
566            fn visit_ident(&mut self, ident: &Ident) {
567                if ident == "Self" {
568                    self.found = true;
569                }
570
571                visit::visit_ident(self, ident);
572            }
573        }
574
575        let mut visit = Visitor { found: false };
576        visit.visit_file(transform);
577
578        if visit.found {
579            return Err(ValidBugs::SelfFoundAfterTransformation {}.into());
580        }
581
582        Ok(())
583    }
584}

590/// Performs the complete executable instance-access transformation for an
591/// implementation.
592///
593/// The transformation first validates the implementation's basic structure,
594/// extracts the instance node and bound, and performs the validations that
595/// depend on the extracted instance information. It then prepares the
596/// implementation for standalone lowering by propagating impl generics and
597/// normalizing instance-bound paths.
598///
599/// The final replacement depends on the requested [`AccessArgs`]. Leaf access
600/// replaces instance-bound associated items with their fixed representations,
601/// while non-leaf access introduces the dynamic arguments and generated
602/// runtime instance selection required to resolve the requested instance.
603/// Finalization removes transformation-only attributes from the resulting
604/// implementation.
605///
606/// Each stage performs its own confirmation so that the complete pipeline
607/// preserves the invariants required by the following stage and produces a
608/// representation suitable for conversion into standalone items.
609#[derive(Debug, Clone)]
610pub(crate) struct InstanceAccessImpl;
611
612impl<'a> Transformation<ItemImpl, AccessArgs> for InstanceAccessImpl {
613    fn raw_transform(
614        &self,
615        transform: &mut ItemImpl,
616        context: &AccessArgs,
617    ) -> Result<(), proc_macro2::TokenStream> {
618        InstanceAccessPreValidation::checked_transform(
619            &InstanceAccessPreValidation,
620            transform,
621            &(),
622        )?;
623        let _ = InstanceNodeExtraction::checked_extract(transform, &())?;
624        let mut inst = InstanceBound::extract_mut(transform, &())?;
625        InstanceAccessPostValidation::checked_transform(
626            &InstanceAccessPostValidation,
627            transform,
628            &inst,
629        )?;
630        InstanceAccessPreReplacement::checked_transform(
631            &InstanceAccessPreReplacement,
632            transform,
633            &inst,
634        )?;
635        InstanceAccessPostReplacement::checked_transform(
636            &InstanceAccessPostReplacement,
637            &mut (transform, &mut inst),
638            context,
639        )?;
640        InstanceAccessFinalize::checked_transform(&InstanceAccessFinalize, transform, context)?;
641        Ok(())
642    }
643
644    fn validate_transform(
645        &self,
646        transform: &ItemImpl,
647        context: Option<&AccessArgs>,
648    ) -> Result<(), proc_macro2::TokenStream> {
649        InstanceAccessPreValidation::validate_transform(
650            &InstanceAccessPreValidation,
651            transform,
652            None,
653        )?;
654        InstanceBound::confirm(None, transform, &())?;
655        InstanceAccessFinalize::validate_transform(&InstanceAccessFinalize, transform, context)?;
656        Ok(())
657    }
658}

664/// Performs the complete documentation instance-access transformation for an
665/// implementation.
666///
667/// The transformation follows the same validation, instance extraction, and
668/// preparation stages as the executable representation, but uses the
669/// documentation-specific replacement instead of generating runtime
670/// non-leaf instance selection. This allows the documentation representation
671/// to expose the generated instance-bound API without carrying the executable
672/// resolution machinery.
673///
674/// After validation and preparation, standalone `Self` references and
675/// instance-bound associated paths and function calls are replaced with their
676/// documentation representations. The transformed implementation is then
677/// finalized so that it can be converted into the standalone items used by the
678/// documentation build.
679///
680/// Each stage confirms its resulting invariants, ensuring that the
681/// documentation representation remains structurally consistent with the
682/// executable transformation while using its separate documentation-facing
683/// replacement rules.
684#[derive(Debug, Clone)]
685pub(crate) struct InstanceAccessImplDoc;

766    }

782// ===============================================================================
783// ``````````````````````````` INSTANCE NODE EXTRACTION ``````````````````````````
784// ===============================================================================
785
786/// Extracts the instance node and bound from the implementation and validates
787/// the structural information required by the subsequent instance-access
788/// transformations.
789///
790/// The extracted node is checked against the expected implementation
791/// generics, their required ordering, the qualified associated type form of
792/// the implementation self type, and the requirement that the implementation
793/// self type is represented as `Self`.
794///
795/// Confirmation verifies both the extracted [`InstanceNodeBound`] and all of
796/// the structural invariants established during extraction.
797#[derive(Debug, Clone)]
798pub(crate) struct InstanceNodeExtraction(InstanceNodeBound);
799
800impl Extraction<ItemImpl> for InstanceNodeExtraction {

805        ValidQAssocImplSelfTy::validate(from, &node)?;
806        ForceSelfTyAsSelf::validate(from, &node)?;
807        RestrictInnerSelfItems::validate(from, &())?;

809    }

811    fn validate_extract(
812        &self,
813        from: &ItemImpl,

815    ) -> Result<(), proc_macro2::TokenStream> {
816        let node = &self.0;
817        InstanceNodeBound::confirm(Some(node), from, &())?;
818        ValidExpectedImplGenerics::confirm(from, node)?;
819        ValidOrderedImplGenerics::confirm(from, node)?;
820        ValidQAssocImplSelfTy::confirm(from, node)?;
821        ForceSelfTyAsSelf::confirm(from, node)?;
822        RestrictInnerSelfItems::confirm(from, &())?;
823        Ok(())
824    }

833/// Performs the validation that depends on the instance-bound information
834/// extracted from the implementation.
835///
836/// This stage verifies that the implementation uses the instance trait only
837/// in the locations supported by instance access, that required `Self`
838/// references use qualified paths, and that associated types do not form
839/// unsupported cross-references. Associated-function arguments are checked
840/// for valid instance-access syntax, and `Self` usage in associated constants
841/// is restricted because those constants are lowered into standalone items.
842///
843/// The validation is performed after instance extraction so that restrictions
844/// involving the extracted instance bound can be checked directly. The
845/// confirmation pass repeats the same checks against the resulting
846/// representation to ensure that the post-validation invariants remain
847/// satisfied.
848#[derive(Debug, Clone)]
849pub(crate) struct InstanceAccessPostValidation;
850
851impl Transformation<ItemImpl, InstanceBound> for InstanceAccessPostValidation {
852    fn raw_transform(
853        &self,
854        transform: &mut ItemImpl,
855        context: &InstanceBound,
856    ) -> Result<(), proc_macro2::TokenStream> {
857        RequireSelfQPaths::validate(&transform, &())?;
858        RestrictAssocTypeCrossReferences::validate(&transform, &())?;
859        ValidAssocFnArgs::validate(&transform, &())?;
860        RestrictSelfInCostAssocs::validate(&transform, &())?;
861        RestrictInstTraitInImpl::validate(&transform, &context)?;
862        RestrictSelfAssocsInInstBound::validate(context, &())?;
863        Ok(())
864    }
865
866    fn validate_transform(
867        &self,
868        transform: &ItemImpl,
869        context: Option<&InstanceBound>,
870    ) -> Result<(), proc_macro2::TokenStream> {
871        let what = transform;
872        RequireSelfQPaths::confirm(what, &())?;
873        RestrictAssocTypeCrossReferences::confirm(what, &())?;
874        ValidAssocFnArgs::confirm(what, &())?;
875        RestrictSelfInCostAssocs::confirm(what, &())?;
876        if let Some(context) = context {
877            RestrictInstTraitInImpl::confirm(what, context)?;
878            RestrictSelfAssocsInInstBound::confirm(context, &())?;
879        }
880        Ok(())
881    }

936// `````````````````````` INSTANCE ACCESS POST-REPLACEMENT ```````````````````````
937// ===============================================================================
938
939/// Performs the final instance-access replacement after the implementation has
940/// been validated, extracted, and prepared for lowering into standalone items.
941///
942/// Standalone `Self` references are first replaced with the concrete
943/// implementation self type. Leaf access then replaces associated types,
944/// `#[sum]` associated types, and associated-function calls using the fixed
945/// instance representation. Non-leaf access makes inferred return error types
946/// explicit, appends the dynamic byte-string arguments required for runtime
947/// instance selection, and replaces associated types and function calls with
948/// their generated non-leaf representations.
949///
950/// Unknown access arguments are rejected because the access keys required for
951/// replacement are unavailable.
952///
953/// The transformation is followed by confirmation of every replacement,
954/// ensuring that standalone `Self` references, associated paths, associated
955/// calls, dynamic arguments, and inferred error types have all been lowered
956/// into their required final representation.
957#[derive(Debug, Clone)]
958pub(crate) struct InstanceAccessPostReplacement;
959
960impl<'a> Transformation<NewMutateSpace<'a>, AccessArgs> for InstanceAccessPostReplacement {
961    fn raw_transform(
962        &self,
963        transform: &mut NewMutateSpace,
964        context: &AccessArgs,
965    ) -> Result<(), proc_macro2::TokenStream> {
966        let args = context;
967        let (transform, bound) = transform;
968
969        ReplaceStandAloneSelf::replace(*bound, &transform)?;
970        ReplaceStandAloneSelf::replace(*transform, &())?;
971
972        match args {
973            AccessArgs::Leaf(leaf) => {
974                ReplaceLeafSumTypeSelfAssocs::replace(transform, &(bound, leaf))?;
975                ReplaceLeafSelfAssocs::replace(transform, &(bound, leaf))?;
976                ReplaceLeafSelfAssocCalls::replace(transform, &(bound, leaf))?;
977            }
978            AccessArgs::Unknown(token) => {
979                return Err(KeysError::ExpectedKeys {
980                    span: token.tokens.span(),
981                }
982                .into());
983            }
984            other => {
985                ReplaceReturnTyInferedError::replace(transform, &())?;
986                AppendDynFnArg::replace(transform, other)?;
987                ReplaceNonLeafSelfAssocs::replace(transform, &(bound, other))?;
988                ReplaceNonLeafSelfAssocCalls::replace(transform, &(bound, other))?;
989            }
990        }
991
992        Ok(())
993    }
994
995    fn validate_transform(
996        &self,
997        transform: &NewMutateSpace<'a>,
998        context: Option<&AccessArgs>,
999    ) -> Result<(), proc_macro2::TokenStream> {
1000        let Some(args) = context else {
1001            return Ok(());
1002        };
1003        let (transform, bound) = transform;
1004
1005        ReplaceStandAloneSelf::confirm(&**bound, &**transform)?;
1006        ReplaceStandAloneSelf::confirm(&**transform, &())?;
1007
1008        match args {
1009            AccessArgs::Leaf(leaf) => {
1010                ReplaceLeafSumTypeSelfAssocs::confirm(transform, &(bound, leaf))?;
1011                ReplaceLeafSelfAssocs::confirm(transform, &(bound, leaf))?;
1012                ReplaceLeafSelfAssocCalls::confirm(transform, &(bound, leaf))?;
1013            }
1014            AccessArgs::Unknown(token) => {
1015                return Err(KeysError::ExpectedKeys {
1016                    span: token.tokens.span(),
1017                }
1018                .into());
1019            }
1020            other => {
1021                ReplaceReturnTyInferedError::confirm(transform, &())?;
1022                AppendDynFnArg::confirm(transform, other)?;
1023                ReplaceNonLeafSelfAssocs::confirm(transform, &(bound, other))?;
1024                ReplaceNonLeafSelfAssocCalls::confirm(transform, &(bound, other))?;
1025            }
1026        }
1027
1028        Ok(())
1029    }
1030}
