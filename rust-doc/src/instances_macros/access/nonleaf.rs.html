13// `````````````````````````` INSTANCE NON-LEAF ACCESS ```````````````````````````
14// ===============================================================================

16//! Resolves non-leaf instance access whose dynamic arguments are supplied at
17//! runtime as additional byte-string function arguments.
18//!
19//! Non-leaf access differs from leaf access ([`crate::access::leaf`]) because
20//! the requested instance is not known as a fixed type replacement. The dynamic
21//! identifiers supplied to the access determine which instance position is selected
22//! at runtime, so non-leaf access introduces additional byte-string arguments to the
23//! generated function.
24//!
25//! For an [`ExprPath`], however, the dynamic identifiers are not part of the
26//! expression itself. The path is transformed into the terminal type
27//! representation ([`crate::node::access::TerminalAccess`]) of the non-leaf instance,
28//! in the same general manner that leaf access performs its fixed type replacement:
29//!
30//! ```text
31//! Self::Assoc
32//!
33//! <InitialInstance as InstanceBound>::Assoc
34//!
35//! <TerminalInstance as InstanceBound<TerminalAccess>>::Assoc
36//! ```
37//!
38//! The difference is that non-leaf access replaces the instance with its
39//! terminal representation rather than directly selecting one fixed instance.
40//! The runtime dynamic identifiers are resolved when an associated function is
41//! invoked.
42//!
43//! ## Expression calls
44//!
45//! Non-leaf function access is supported only through an [`ExprCall`]. A bare
46//! function path such as:
47//!
48//! ```text
49//! Self::get
50//! ```
51//!
52//! is not a valid non-leaf access form. The function must be invoked:
53//!
54//! ```text
55//! Self::get()
56//! Self::get(x, id1)
57//! Self::get(x, id1, id2)
58//! ```
59//!
60//! This distinction is important because the call provides the additional
61//! runtime arguments through which the dynamic instance positions are
62//! resolved. Once `Self::get(...)` is taken as an [`ExprCall`], the
63//! transformation is no longer limited to replacing the type represented by
64//! the path. The call becomes the entry point for resolving the generated
65//! instance hierarchy.
66//!
67//! ## Dynamic instance resolution
68//!
69//! Resolution begins from the [`crate::node::state::INITIAL_NODE`] and derives
70//! the instance states that can be reached for the supplied dynamic identifiers. The
71//! resolver derives the corresponding counters, borders, affiliate instances,
72//! and accessor expressions required at each reachable depth ([`DerivedItems`]).
73//!
74//! The dynamic identifiers are converted into checker expressions which search
75//! the appropriate final counter collections. A successful lookup produces the
76//! numeric position of the identifier:
77//!
78//! ```text
79//! Some(index)
80//! ```
81//!
82//! An identifier that does not exist produces:
83//!
84//! ```text
85//! None
86//! ```
87//!
88//! These results are combined with the generated accessors through nested
89//! `match` expressions. Each successful match selects the accessor belonging
90//! to the resolved position and, when another dynamic dimension remains,
91//! continues resolution at the next level.
92//!
93//! Conceptually, for two dynamic identifiers, the generated expression has the
94//! following form:
95//!
96//! ```text
97//! match check(id1) {
98//!     Some(i1) => match check_next(i1, id2) {
99//!         Some(i2) => accessor(i1, i2),
100//!         None => Error::OutOfRange,
101//!     },
102//!     None => Error::OutOfRange,
103//! }
104//! ```
105//!
106//! `Error::OutOfRange` represents a dynamic identifier that cannot be found in
107//! the corresponding counter collection. `Error::Exhausted` represents a
108//! numeric position for which no generated accessor exists but its evident that
109//! the dynamic identifier is available.
110//!
111//! The transformation therefore derives the runtime selection expression for
112//! every reachable depth rather than attempting to resolve the dynamic
113//! identifiers statically. The generated match clauses encode the possible
114//! counter positions, while the generated accessor expressions represent the
115//! instance state associated with each position.
116//!
117//! ## Derived hierarchy state
118//!
119//! [`ExprCallEssentials`] collects the information required to construct this
120//! resolution, including the generated node representations, initial and final
121//! instances, counter indexes, dynamic identifiers, prefixes, instance trait,
122//! surrounding generics, and hierarchy depths.
123//!
124//! [`BorderInfo`] represents the state at an individual counter boundary.
125//! Resolution of a border determines the affiliate instance and counter needed
126//! to continue toward the next depth. [`DerivedItems`] collects the identifier
127//! checkers, generated aliases, accessor expressions, and border information
128//! produced while deriving the complete hierarchy.
129//!
130//! Intermediate types are materialized as generated aliases so that the
131//! derived instance states can be referenced by the generated expressions.
132//! [`Projection`] then describes the operation performed on each resolved
133//! instance, such as projecting an associated item or invoking an associated
134//! function.
135//!
136//! The final result of the transformation is therefore a complete expression
137//! whose runtime arguments select the appropriate positions in the generated
138//! instance hierarchy, whose match clauses perform that selection, whose
139//! accessors represent the corresponding instance states, and whose error
140//! branches handle positions that cannot be resolved.

181/// Resolves a non-leaf instance path to its terminal instance node.
182///
183/// This transformation resolves the selected terminal access for that
184/// associated type and rewrites the QSelf to the corresponding terminal twin node.
185///
186/// The supplied [`IntList`] identifies the instance-counter positions used to
187/// construct the [`TerminalAccess`] projection. The projection is inserted
188/// into the trait path at the appropriate counter position, replacing the
189/// original counter representation with the generated access projection.
190///
191/// Conceptually, an input path of the form:
192///
193/// ```text
194/// <AssocType as InstanceTrait<...>>::Assoc
195/// ```
196///
197/// is transformed to a path whose QSelf is the generated terminal twin of
198/// `AssocType` and whose trait path contains the resolved terminal access:
199///
200/// ```text
201/// <AssocTypeTerminalTwin as InstanceTrait<...TerminalAccess...>>::Assoc
202/// ```
203///
204/// The terminal twin identifies the concrete terminal node reached by the
205/// access, while the transformed trait path carries the corresponding
206/// terminal access projection.
207///
208#[derive(Debug, Clone)]
209pub(crate) struct InstanceNonLeafTerminalPathAccess;
210
211impl<'a> Transformation<Expr, (&ExprPath, &IntList)> for InstanceNonLeafTerminalPathAccess {
212    fn raw_transform(
213        &self,
214        transform: &mut Expr,
215        context: &(&ExprPath, &IntList),
216    ) -> Result<(), proc_macro2::TokenStream> {
217        let &(expr_path, indexes) = context;
218        let mut expr = expr_path.clone();
219
220        let Some(q_base) = &mut expr.qself else {
221            return Err(ResolveErrors::ExprPathRequiresQSelf {
222                expr_path: expr.clone(),
223            }
224            .into());
225        };
226
227        let mut base_ty = &mut *q_base.ty;
228
229        let Type::Path(type_path) = &mut base_ty else {
230            return Err(ResolveErrors::QSelfNotTypePath {
231                q_self: base_ty.clone(),
232            }
233            .into());
234        };
235
236        let pos = q_base.position;
237        let trait_p = &mut expr.path.segments.iter_mut().take(pos);
238
239        let Some(trait_path) = trait_p.last() else {
240            return Err(ResolveErrors::InstanceTraitPathNotFound {
241                path: expr.path.clone(),
242            }
243            .into());
244        };
245
246        subscriber_call_path(&type_path, trait_path, indexes)?;
247
248        let Some(last) = type_path.path.segments.last_mut() else {
249            return Err(ResolveErrors::QSelfNotTypePath {
250                q_self: base_ty.clone(),
251            }
252            .into());
253        };
254        last.ident = gen_type_ident_from_ident_with_suffix::<InstanceTerminalNode>(
255            &last.ident.clone(),
256            TERMINAL_TWIN_NODE,
257        );
258
259        *transform = Expr::Path(expr);
260
261        Ok(())
262    }
263
264    fn validate_transform(
265        &self,
266        transform: &Expr,
267        context: Option<&(&ExprPath, &IntList)>,
268    ) -> Result<(), proc_macro2::TokenStream> {
269        let Some(context) = context else {
270            return Ok(());
271        };
272
273        let Expr::Path(expr) = transform else {
274            return Err(ResolveBugs::InstanceNonLeafPathResolutionYieldedNonPath {}.into());
275        };
276        let &(expr_path, indexes) = context;
277
278        let Some(q_base) = &expr.qself else {
279            return Err(ResolveBugs::ExprPathRequiresQSelf {}.into());
280        };
281
282        let pos = q_base.position;
283        let trait_p = expr.path.segments.iter().take(pos);
284        let Some(trait_path) = trait_p.last() else {
285            return Err(ResolveBugs::InstanceTraitPathNotFound {}.into());
286        };
287
288        let Some(context_q_base) = &expr_path.qself else {
289            return Err(ResolveBugs::ExprPathRequiresQSelf {}.into());
290        };
291
292        let Type::Path(context_type_path) = &*context_q_base.ty else {
293            return Err(ResolveBugs::QSelfNotTypePath {}.into());
294        };
295
296        validate_subscriber_call_path(&context_type_path, trait_path, indexes)?;
297
298        let Some(q_base) = &expr.qself else {
299            return Err(ResolveBugs::InstanceNonLeafPathResolvedQSelfMissing {}.into());
300        };
301
302        let Type::Path(type_path) = &*q_base.ty else {
303            return Err(ResolveBugs::InstanceNonLeafPathResolvedQSelfInvalid {}.into());
304        };
305
306        let Some(last) = type_path.path.segments.last() else {
307            return Err(ResolveBugs::InstanceNonLeafPathResolvedQSelfInvalid {}.into());
308        };
309
310        let Some(context_last) = context_type_path.path.segments.last() else {
311            return Err(ResolveBugs::QSelfNotTypePath {}.into());
312        };
313        if last.ident
314            != gen_type_ident_from_ident_with_suffix::<InstanceTerminalNode>(
315                &context_last.ident.clone(),
316                TERMINAL_TWIN_NODE,
317            )
318        {
319            return Err(ResolveBugs::InstanceNonLeafPathResolvedInconsistentAccess {}.into());
320        }
321
322        Ok(())
323    }
324}

330/// Resolves the terminal subscriber access for an associated type.
331fn subscriber_call_path(
332    assoc_ty: &TypePath,
333    trait_path: &mut PathSegment,
334    indexes: &IntList,
335) -> Result<(), TokenStream> {
336    let mut global_ty = assoc_ty.clone();
337    let Some(assoc) = global_ty.path.segments.last_mut() else {
338        return Err(ResolveErrors::AssocQSelfLastIdentUnavailable {
339            path: global_ty.path.clone(),
340        }
341        .into());
342    };
343    let ident = &mut assoc.ident;
344    *ident =
345        gen_type_ident_from_ident_with_suffix::<InstanceTerminalNode>(ident, TERMINAL_GLOBAL_NODE);
346    let self_ty: Type = parse_quote!(#global_ty);
347
348    let base_ty = Type::Path(assoc_ty.clone());
349    let context = (&base_ty, indexes).into();
350    let bound = TerminalAccess::checked_extract(&context, &())?;
351    let t_context = (&self_ty, context, false).into();
352    TerminalAccess::checked_transform(&bound, trait_path, &t_context)?;
353
354    Ok(())
355}
356
357/// Validates the terminal subscriber access for an associated type.
358fn validate_subscriber_call_path(
359    assoc_path: &TypePath,
360    trait_path: &PathSegment,
361    indexes: &IntList,
362) -> Result<(), TokenStream> {
363    let mut global_ty = assoc_path.clone();
364    let Some(assoc) = global_ty.path.segments.last_mut() else {
365        return Err(ResolveBugs::AssocQSelfLastIdentUnavailable {}.into());
366    };
367    let ident = &mut assoc.ident;
368    *ident =
369        gen_type_ident_from_ident_with_suffix::<InstanceTerminalNode>(ident, TERMINAL_GLOBAL_NODE);
370    let self_ty: Type = parse_quote!(#global_ty);
371
372    let base_ty = Type::Path(assoc_path.clone());
373    let context = (&base_ty, indexes).into();
374    let bound = TerminalAccess::checked_extract(&context, &())?;
375    let t_context = (&self_ty, context, true).into();
376    TerminalAccess::validate_transform(&bound, trait_path, Some(&t_context))?;
377    Ok(())
378}

388/// Describes a projection from a tokenized base path to a path segment,
389/// associated-function call, or trait-associated function call.
390///
391/// A projection stores the syntactic components that follow a base path.
392/// [`Projection::project`] materializes those components by inserting the
393/// supplied tokens as the base of the projection.
394///
395/// The base itself is not stored in the projection. It is supplied separately
396/// to [`Projection::project`] as a [`TokenStream`], allowing the same
397/// projection description to be materialized against different bases.
398pub(crate) enum Projection<'a> {
399    /// Projects a path segment from the supplied base.
400    ///
401    /// Given:
402    ///
403    /// ```text
404    /// tokens  = Base
405    /// segment = Item
406    /// ```
407    ///
408    /// produces:
409    ///
410    /// ```text
411    /// Base::Item
412    /// ```
413    ///
414    /// This represents a simple path extension without a function call.
415    #[allow(dead_code)]
416    Segment { segment: &'a PathSegment },
417
418    /// Projects a direct associated-function call from the supplied base.
419    ///
420    /// Given:
421    ///
422    /// ```text
423    /// tokens = Base
424    /// call   = get
425    /// args   = [arg1, arg2]
426    /// ```
427    ///
428    /// produces:
429    ///
430    /// ```text
431    /// Base::get(arg1, arg2)
432    /// ```
433    ///
434    /// When no arguments are stored, the resulting call is emitted as:
435    ///
436    /// ```text
437    /// Base::get()
438    /// ```
439    Call {
440        call: &'a PathSegment,
441        args: Vec<&'a Expr>,
442    },
443
444    /// Projects a function call through a path segment and an optional trait
445    /// bound.
446    ///
447    /// When a trait bound is present, the projection produces a qualified
448    /// trait-associated call:
449    ///
450    /// ```text
451    /// <Base::Item as Trait>::get(arg)
452    /// ```
453    ///
454    /// When no trait bound is present, the projection produces an ordinary
455    /// nested path call:
456    ///
457    /// ```text
458    /// Base::Item::get(arg)
459    /// ```
460    #[allow(dead_code)]
461    TraitCall {
462        segment: &'a PathSegment,
463        bound: Option<&'a Path>,
464        call: &'a PathSegment,
465        args: Vec<&'a Expr>,
466    },
467}
468
469impl<'a> Projection<'a> {
470    fn project(&self, tokens: &TokenStream) -> Expr {
471        match self {
472            Projection::Segment { segment } => {
473                parse_quote!(#tokens::#segment)
474            }
475
476            Projection::Call { call, args } => {
477                if !args.is_empty() {
478                    parse_quote!(#tokens::#call(#(From::from(#args)),*))
479                } else {
480                    parse_quote!(#tokens::#call())
481                }
482            }
483
484            Projection::TraitCall {
485                segment,
486                bound,
487                call,
488                args,
489            } => {
490                if let Some(bound) = bound {
491                    if !args.is_empty() {
492                        parse_quote!(
493                            <#tokens::#segment as #bound>::#call(#(From::from(#args)),*)
494                        )
495                    } else {
496                        parse_quote!(
497                            <#tokens::#segment as #bound>::#call()
498                        )
499                    }
500                } else {
501                    if !args.is_empty() {
502                        parse_quote!(
503                            #tokens::#segment::#call(#(From::from(#args)),*)
504                        )
505                    } else {
506                        parse_quote!(
507                            #tokens::#segment::#call()
508                        )
509                    }
510                }
511            }
512        }
513    }
514}

520/// Resolves non-leaf instance-associated function calls through the generated
521/// instance hierarchy.
522///
523/// The transformation derives the subscriber call from the node, instance
524/// access arguments, and projection, resolving dynamic identifiers through the
525/// corresponding counter dimensions before producing the final expression.
526#[derive(Debug, Clone)]
527pub(crate) struct InstanceNonLeafExprCallAccess;
528
529type ExprCallContext<'a> = (&'a ExprCall, &'a Generics, &'a AccessArgs);
530
531impl<'a> Transformation<Expr, ExprCallContext<'a>> for InstanceNonLeafExprCallAccess {
532    fn raw_transform(
533        &self,
534        transform: &mut Expr,
535        context: &ExprCallContext<'a>,
536    ) -> Result<(), proc_macro2::TokenStream> {
537        let &(expr_call, generics, args) = context;
538
539        let expr = &*expr_call.func;
540
541        let arguments = expr_call.args.iter().collect::<Vec<_>>();
542
543        let Expr::Path(expr_path) = expr else {
544            return Err(ResolveErrors::ExprCallPathNotExprPath { expr: expr.clone() }.into());
545        };
546
547        let Some(q_base) = &expr_path.qself else {
548            return Err(ResolveErrors::ExprPathRequiresQSelf {
549                expr_path: expr_path.clone(),
550            }
551            .into());
552        };
553
554        let base_ty = &*q_base.ty;
555        let Type::Path(type_path) = &*base_ty else {
556            return Err(ResolveErrors::QSelfNotTypePath {
557                q_self: base_ty.clone(),
558            }
559            .into());
560        };
561
562        let pos = q_base.position;
563        let trait_p = expr_path.path.segments.iter().take(pos);
564
565        let Some(inst_trait) = trait_p.last() else {
566            return Err(ResolveErrors::InstanceTraitPathNotFound {
567                path: expr_path.path.clone(),
568            }
569            .into());
570        };
571
572        let Some(segment) = expr_path.path.segments.last() else {
573            return Err(ResolveErrors::ExprCallPathNotExprPath { expr: expr.clone() }.into());
574        };
575
576        let mutate = subscriber_call_expr(
577            type_path,
578            &mut inst_trait.clone(),
579            &Projection::Call {
580                call: segment,
581                args: arguments,
582            },
583            &mut generics.clone(),
584            args,
585        )?;
586
587        *transform = mutate;
588
589        Ok(())
590    }
591
592    fn validate_transform(
593        &self,
594        _transform: &Expr,
595        context: Option<&ExprCallContext<'a>>,
596    ) -> Result<(), proc_macro2::TokenStream> {
597        let Some((expr_call, ..)) = context else {
598            return Ok(());
599        };
600
601        let expr = &*expr_call.func;
602
603        let Expr::Path(expr_path) = expr else {
604            return Err(ResolveBugs::ExprCallPathNotExprPath {}.into());
605        };
606
607        let Some(q_base) = &expr_path.qself else {
608            return Err(ResolveBugs::ExprPathRequiresQSelf {}.into());
609        };
610
611        let base_ty = &q_base.ty;
612
613        let Type::Path(_) = &**base_ty else {
614            return Err(ResolveBugs::QSelfNotTypePath {}.into());
615        };
616
617        let pos = q_base.position;
618        let trait_p = expr_path.path.segments.iter().take(pos);
619        let Some(_) = trait_p.last() else {
620            return Err(ResolveBugs::InstanceTraitPathNotFound {}.into());
621        };
622
623        let Some(_) = expr_path.path.segments.last() else {
624            return Err(ResolveBugs::ExprCallPathNotExprPath {}.into());
625        };
626
627        Ok(())
628    }
629}

631/// Describes the generated type representations associated with an instance
632/// node and its position within the instance hierarchy (see [`crate::node`]).
633///
634/// Each representation corresponds to a distinct role of the same instance
635/// node:
636///
637/// - `global` - the generated global representation of the node ([`GLOBAL_NODE`]);
638/// - `initial` - the representation used as the initial boundary of the node ([`INITIAL_NODE`]);
639/// - `final_` - the representation used as the final boundary of the node ([`FINAL_NODE`]); and
640/// - `node` - the representation identifying the node itself.
641///
642/// These representations are derived together because the instance-node
643/// transformation needs to relate the node's global, boundary, and concrete
644/// forms when constructing the generated instance hierarchy.
645///
646/// The four types therefore describe the same logical instance node from
647/// different positions in the generated type-level hierarchy.
648#[derive(Debug)]
649struct NodeNeighbours {
650    global: TypePath,
651    initial: TypePath,
652    final_: TypePath,
653    node: TypePath,
654}
655
656impl NodeNeighbours {
657    /// Derives the generated type paths associated with an instance node.
658    ///
659    /// The supplied `node` represents the original instance node. Its final path
660    /// segment identifies the node, and that identifier is used to derive the
661    /// corresponding generated representations:
662    ///
663    /// ```text
664    /// Node
665    /// |---NodeInitial
666    /// |---NodeFinal
667    /// |---NodeGlobal
668    /// ```
669    ///
670    /// The original path is preserved as `node`, while its final segment is
671    /// replaced with the generated [`InstanceNode`] variants for `initial`,
672    /// `final_`, and `global`.
673    ///
674    /// All other segments of the original path, including its generic arguments
675    /// and qualification, are preserved unchanged.
676    fn get_node_path(node: &TypePath) -> Result<Self, TokenStream> {
677        let Some(node_seg) = node.path.segments.last() else {
678            return Err(ResolveErrors::QSelfNotTypePath {
679                q_self: Type::Path(node.clone()),
680            }
681            .into());
682        };
683
684        let node_ident = &node_seg.ident;
685
686        let mut try_ty = node.clone();
687
688        let initial_ident =
689            gen_type_ident_from_ident_with_suffix::<InstanceNode>(node_ident, INITIAL_NODE);
690        try_ty.path.segments.last_mut().unwrap().ident = initial_ident.clone();
691        let init_ty = try_ty.clone();
692
693        let final_ident =
694            gen_type_ident_from_ident_with_suffix::<InstanceNode>(node_ident, FINAL_NODE);
695        try_ty.path.segments.last_mut().unwrap().ident = final_ident.clone();
696        let final_ty = try_ty.clone();
697
698        let global_ident =
699            gen_type_ident_from_ident_with_suffix::<InstanceNode>(node_ident, GLOBAL_NODE);
700        try_ty.path.segments.last_mut().unwrap().ident = global_ident.clone();
701        let global_ty = try_ty.clone();
702
703        Ok(Self {
704            global: global_ty,
705            initial: init_ty,
706            final_: final_ty,
707            node: node.clone(),
708        })
709    }
710
711    /// Derives the initial and final instance paths for a node.
712    ///
713    /// The supplied `inst` contains the instance path whose node type argument
714    /// identifies the current node. The node's generic arguments are first removed
715    /// at the positions specified by `indexes`, and two copies of the resulting
716    /// path are created.
717    ///
718    /// The first copy receives the generated `initial` node type, while the second
719    /// receives the generated `final_` node type:
720    ///
721    /// ```text
722    /// inst<..., Node, ...>
723    ///       |
724    ///       |---initial -> inst<..., NodeInitial, ...>
725    ///       |---final   -> inst<..., NodeFinal, ...>
726    /// ```
727    ///
728    /// Only the node type argument at first index-value of `indexes` is replaced; the surrounding path
729    /// structure is preserved.
730    ///
731    /// The returned paths represent the initial and final instance boundaries of
732    /// the node and are used when constructing the corresponding instance
733    /// hierarchy representations.
734    fn get_node_instances(
735        &self,
736        inst: &mut PathSegment,
737        indexes: &IntList,
738    ) -> Result<(PathSegment, PathSegment), TokenStream> {
739        let NodeNeighbours {
740            initial, final_, ..
741        } = &self;
742        let initial_ty = initial;
743        let final_ty = final_;
744
745        remove_gen_args(inst, indexes)?;
746
747        let mut initial_instance = inst.clone();
748        insert_gen_arg(&mut initial_instance, indexes, || {
749            Ok(GenericArgument::Type(parse_quote!(#initial_ty)))
750        })?;
751
752        let mut final_instance = inst.clone();
753        insert_gen_arg(&mut final_instance, indexes, || {
754            Ok(GenericArgument::Type(parse_quote!(#final_ty)))
755        })?;
756
757        Ok((initial_instance, final_instance))
758    }
759
760    /// Adds a where-predicate that confirms the supplied prefixes through
761    /// [`OnSetAccess`] on the node's global representation.
762    ///
763    /// For example, prefixes such as `b"x", b"y"` are resolved through
764    /// [`OnSetAccess`] to produce the corresponding access bound, which is then
765    /// added as a constraint on the generics used throughout all declarations:
766    ///
767    /// ```text
768    /// NodeInitial: <OnSetAccess for GlobalNode using [x, y]>
769    /// ```
770    ///
771    /// This ensures that the generated initial node satisfies the requested
772    /// prefix access.
773    fn prefix_bound(
774        &self,
775        generics: &mut Generics,
776        indexes: &IntList,
777        prefixes: &BStringList,
778    ) -> Result<(), TokenStream> {
779        let NodeNeighbours {
780            initial,
781            global,
782            node,
783            ..
784        } = &self;
785        let initial_ty = initial;
786        let global_ty = global;
787        let node_ty = node;
788
789        let self_ty: Type = parse_quote!(#node_ty);
790        let global_ty: Type = parse_quote!(#global_ty);
791        let context = (&self_ty, indexes, prefixes).into();
792        let onset = OnSetAccess::checked_extract(&context, &())?;
793        let bound = ExactAccess::checked_extract(&onset, &global_ty)?.bound;
794        let where_pred: WherePredicate = parse_quote!(
795            #initial_ty : #bound
796        );
797        generics.make_where_clause().predicates.push(where_pred);
798
799        Ok(())
800    }
801}

804/// instance associated function call.
805///
806/// The fields retain the node representations, resolved instance paths,
807/// access metadata, generics, and depth information needed across the
808/// transformation steps.
809#[derive(Debug)]
810struct ExprCallEssentials {
811    /// Generated global, initial, final, and original node representations.
812    neighbours: NodeNeighbours,
813
814    /// Initial and final instance paths derived from the node.
815    instances: (PathSegment, PathSegment),
816
817    /// Type-level generic positions identifying the instance-counters being accessed.
818    indexes: IntList,
819
820    /// DYnamic Identifiers used to select the instance values.
821    idents: BStrInputList,
822
823    /// Optional prefixes used for prefix-based instance access.
824    #[allow(dead_code)]
825    prefixes: Option<BStringList>,
826
827    /// Original instance path from which the derived instances are built.
828    inst: PathSegment,
829
830    /// Generic parameters and where-clause constraints for the call.
831    generics: Generics,
832
833    /// First and Second order depths of the instance within the hierarchy.

835}

837/// Holds the intermediate state produced while deriving a single counter
838/// border.
839///
840/// `index` identifies the counter position being processed, `node` is the
841/// current node type at that position, `inst` is the instance trait segment
842/// used to resolve the node, and `aliases` contains the type aliases generated
843/// while deriving the border.
844#[derive(Debug, Clone)]
845struct BorderInfo {
846    /// Counter position represented by this border.
847    index: usize,
848
849    /// Node type from which the border is derived.
850    node: Type,
851
852    /// Instance trait segment used to resolve the node.
853    inst: PathSegment,
854
855    /// Type aliases generated while constructing this border.
856    aliases: Vec<ItemType>,
857}

859/// Collects all intermediate artifacts needed to assemble the final
860/// dynamic-counter expression.
861#[derive(Debug, Clone)]
862struct DerivedItems {
863    /// Expressions that resolve dynamic identifiers to counter positions.
864    ident_checkers: Vec<Expr>,
865
866    /// Type aliases generated while deriving each counter chain.
867    aliases: Vec<Vec<ItemType>>,
868
869    /// Accessor expressions generated for each counter position.
870    exprs: Vec<Vec<Expr>>,
871
872    /// Type aliases generated for the borders between counter chains.

876impl ExprCallEssentials {
877    /// Derives and collects all components required to transform an associated
878    /// function call from the supplied node and access arguments.
879    ///
880    /// This resolves the node's generated representations, instance paths,
881    /// identifiers, optional prefixes, generic constraints, and hierarchy depths
882    /// into a single [`ExprCallEssentials`] value.
883    ///
884    /// When prefixes are present, their corresponding [`OnSetAccess`] bound is
885    /// added to `generics` to confirm that the requested prefix access is valid.
886    /// Dynamic identifiers are limited to at most two entries.
887    fn get(
888        node: &TypePath,
889        inst: &mut PathSegment,
890        args: &AccessArgs,
891        generics: &mut Generics,
892    ) -> Result<Self, TokenStream> {
893        let nodes = NodeNeighbours::get_node_path(node)?;
894        let indexes = AccessArgsIndexes::checked_utilize(args, &())?.0;
895        let (initial_instance, final_instance) = nodes.get_node_instances(inst, &indexes)?;
896        let idents = AccessArgsIdents::checked_extract(args, &())?;
897        let AccessArgsIdents { prefixes, idents } = idents;
898        if idents.exprs.len() > 2 {
899            return Err(ResolveErrors::MaxDynCounters { list: idents }.into());
900        }
901        let prefix_idents = if prefixes.bytes.is_empty() {
902            None
903        } else {
904            Some(prefixes)
905        };
906        if let Some(prefixes) = &prefix_idents {
907            nodes.prefix_bound(generics, &indexes, prefixes)?;
908        }
909        let depths = AccessArgsDepths::checked_extract(args, &())?.0;
910        Ok(Self {
911            neighbours: nodes,
912            instances: (initial_instance, final_instance),
913            indexes: indexes.clone(),
914            idents,
915            prefixes: prefix_idents,
916            inst: inst.clone(),
917            generics: generics.clone(),
918            depths,
919        })
920    }
921
922    /// Builds identifier-checker expressions for the supplied dynamic identifiers.
923    ///
924    /// Each expression searches the final instance's hash collection for the hash
925    /// of one identifier. The search starts at the corresponding initial-instance
926    /// length, so the resulting slice represents only the portion relevant to that
927    /// access and therefore produces an `Option<usize>`:
928    ///
929    /// ```text
930    /// Some(index)  -> the identifier was found at that position
931    /// None         -> the identifier was not found
932    /// ```
933    ///
934    /// The indexes and identifiers are processed in reverse order because the
935    /// generated checker expressions correspond to the access hierarchy from the
936    /// innermost identifier back toward the outermost one.
937    fn ident_checkers(&self) -> Result<Vec<Expr>, TokenStream> {
938        let ExprCallEssentials {
939            neighbours,
940            instances,
941            indexes,
942            idents,
943            ..
944        } = &self;
945        let NodeNeighbours { node, .. } = neighbours;
946        let self_ty = node;
947        let (initial_instance, final_instance) = instances;
948
949        let crate_of = Instance::support_crate();
950        let rev_indexes = indexes.ints.iter().rev();
951        let rev_idents = idents.exprs.iter().rev();
952
953        let mut checker_expr = Vec::new();
954
955        for (index, ident) in rev_indexes.zip(rev_idents) {
956            let given = parse_pos_usize(index)?;
957
958            let arr_len = gen_type_ident_with_suffix::<CounterIdentCollectionLenTypeNum>(Some(
959                given.to_string().as_bytes(),
960            ));
961
962            let initial_len: Expr = parse_quote!(<<#self_ty as #initial_instance>::#arr_len as #crate_of::Unsigned>::USIZE);
963
964            let arr = gen_const_ident_with_suffix::<CounterIdentHashCollectionGenArray>(Some(
965                given.to_string().as_bytes(),
966            ));
967
968            let final_arr: Expr = parse_quote!(<#self_ty as #final_instance>::#arr);
969
970            let relative_slc: Expr = parse_quote!(&#final_arr[#initial_len -1 ..]);
971
972            let derive: Expr = parse_quote!(
973                #crate_of::ident_check(
974                    #relative_slc,
975                    &#crate_of::hash_ident(#ident),
976                )
977            );
978
979            checker_expr.push(derive);
980        }
981
982        if checker_expr.is_empty() {
983            return Err(ResolveBugs::IdentCheckerExprsEmpty {}.into());
984        }
985
986        Ok(checker_expr)
987    }
988
989    /// Consumes the current border and prepares the derived state required to
990    /// construct the next counter border.
991    ///
992    /// The current border provides the floor instance and floor counter
993    /// (see [`crate::traits::affiliates`]) for the current counter position.
994    /// These are resolved through the current border's trait segment, then used to
995    /// derive the corresponding next affiliate instance and next affilaite counters
996    /// (from the relative position).
997    ///
998    /// The newly derived instance and counter become the state of `border` itself,
999    /// so the updated border can be used as the input when processing the next
1000    /// counter position:
1001    ///
1002    /// ```text
1003    /// current border
1004    ///      |---FloorAffiliateInstance
1005    ///      |---FloorAffiliateCounter
1006    ///             |---NextAffiliateInstance
1007    ///             |---NextAffiliateCounters
1008    ///                     |
1009    ///              next border state
1010    /// ```
1011    ///
1012    /// Type aliases are generated for the intermediate types so that the derived
1013    /// types can be used in the resulting generic paths while preserving the
1014    /// generics of the surrounding call.
1015    ///
1016    /// The resulting `border.node`, `border.inst`, and `border.aliases` therefore
1017    /// represent the starting state from which the next counter border can be
1018    /// constructed.
1019    fn take_border<'a>(
1020        &self,
1021        border: &mut BorderInfo,
1022        counter: &mut usize,
1023    ) -> Result<(), TokenStream> {
1024        let self_type = &border.node;
1025        let trait_seg = &border.inst;
1026        let given = &border.index;
1027
1028        let cleaned_inst = &self.inst;
1029        let indexes = &self.indexes;
1030        let generics = &self.generics;
1031
1032        let next_inst_ident = gen_type_ident::<NextAffiliateInstance>();
1033        let next_counter_ident = gen_type_ident::<NextAffiliateCounters>();
1034        let floor_inst_ident = gen_type_ident_with_suffix::<FloorAffiliatesInstances>(Some(
1035            given.to_string().as_bytes(),
1036        ));
1037        let floor_counter_ident = gen_type_ident_with_suffix::<FloorAffiliatesCounters>(Some(
1038            given.to_string().as_bytes(),
1039        ));
1040
1041        let mut border_type_aliases = Vec::new();
1042
1043        let floor_inst: Type = parse_quote!(<#self_type as #trait_seg>::#floor_inst_ident);
1044        let floor_counter: Type = parse_quote!(<#self_type as #trait_seg>::#floor_counter_ident);
1045
1046        let [floor_inst, floor_counter] = make_type(
1047            [&floor_inst, &floor_counter],
1048            &mut border_type_aliases,
1049            counter,
1050            generics,
1051        );
1052
1053        let mut floor_trait_seg = cleaned_inst.clone();
1054        insert_gen_arg(&mut floor_trait_seg, indexes, || {
1055            Ok(GenericArgument::Type(floor_counter))
1056        })?;
1057
1058        let floor_next_inst: Type =
1059            parse_quote!(<#floor_inst as #floor_trait_seg>::#next_inst_ident);
1060        let floor_next_counter: Type =
1061            parse_quote!(<#floor_inst as #floor_trait_seg>::#next_counter_ident);
1062
1063        let [floor_next_inst, floor_next_counter] = make_type(
1064            [&floor_next_inst, &floor_next_counter],
1065            &mut border_type_aliases,
1066            counter,
1067            generics,
1068        );
1069
1070        let mut floor_next_trait_seg = cleaned_inst.clone();
1071        insert_gen_arg(&mut floor_next_trait_seg, indexes, || {
1072            Ok(GenericArgument::Type(floor_next_counter))
1073        })?;
1074
1075        border.node = floor_next_inst;
1076        border.inst = floor_next_trait_seg;
1077        border.aliases = border_type_aliases;
1078
1079        Ok(())
1080    }
1081
1082    /// Derives the type aliases, accessor expressions, and border aliases required
1083    /// to construct the final dynamic-counter expression.
1084    ///
1085    /// The derivation walks the counter arguments from the innermost counter toward
1086    /// the outer counters. For each counter, it builds the corresponding border
1087    /// and then follows the `NextAffiliateInstance` / `NextAffiliateCounters`
1088    /// chain to produce the accessor expression for every possible position.
1089    ///
1090    /// The resulting [`DerivedItems`] contains:
1091    ///
1092    /// - `ident_checkers` - expressions that resolve each dynamic identifier to
1093    ///   its position within the corresponding final counter collection;
1094    /// - `aliases` - type aliases required by the generated intermediate instance
1095    ///   and counter types;
1096    /// - `exprs` - accessor expressions arranged by counter position;
1097    /// - `borders` - type aliases required by the derived counter borders.
1098    ///
1099    /// The `projection` determines what is projected from each derived instance
1100    /// state. The generated expressions are retained separately from the aliases
1101    /// and borders because [`Self::derive_expr`] later assembles them into the nested
1102    /// runtime index-selection logic.
1103    fn derive_items<'a>(
1104        &self,
1105        mut count: &mut usize,
1106        projection: &Projection<'a>,
1107    ) -> Result<DerivedItems, TokenStream> {
1108        let ident_checkers = self.ident_checkers()?;
1109
1110        let mut aliases: Vec<Vec<ItemType>> = Vec::new();
1111        let mut exprs: Vec<Vec<Expr>> = Vec::new();
1112        let mut borders: Vec<Vec<ItemType>> = Vec::new();
1113
1114        let (inner, outer) = self.depths;
1115
1116        if inner == 0 {
1117            return Err(ResolveBugs::DepthIsZero {}.into());
1118        };
1119
1120        let next_inst_ident = gen_type_ident::<NextAffiliateInstance>();
1121        let next_counter_ident = gen_type_ident::<NextAffiliateCounters>();
1122
1123        let rev_indexes = self.indexes.ints.iter().rev();
1124        let rev_idents = self.idents.exprs.iter().rev();
1125
1126        let mut args_iter = rev_indexes.clone().zip(rev_idents.clone());
1127
1128        let (last, _) = args_iter.next().unwrap();
1129
1130        let mut given = parse_pos_usize(last)?;
1131
1132        let node = &self.neighbours.node;
1133        let mut self_type: Type = parse_quote!(#node);
1134        let initial_instance = &self.instances.0;
1135        let mut trait_seg = initial_instance.clone();
1136
1137        for _ in 0..outer + 1 {
1138            let archive_self_type = self_type.clone();
1139            let archive_trait_seg = trait_seg.clone();
1140
1141            let mut next_exists = None;
1142
1143            let mut in_aliases = Vec::new();
1144            let mut in_exprs = Vec::new();
1145            let mut in_borders = Vec::new();
1146
1147            in_borders.push(Vec::new());
1148
1149            // CURRENT ARGUMENT BLOCK
1150            for _ in 0..inner {
1151                let mut border = BorderInfo {
1152                    index: given,
1153                    node: self_type.clone(),
1154                    inst: trait_seg.clone(),
1155                    aliases: Vec::new(),
1156                };
1157                self.take_border(&mut border, &mut count)?;
1158
1159                let mut aliases = Vec::new();
1160                let mut accessors = Vec::new();
1161
1162                // CHAIN
1163                for i in 0..inner {
1164                    if i > 0 {
1165                        let next_inst: Type = parse_quote!(
1166                            <#self_type as #trait_seg>::#next_inst_ident
1167                        );
1168
1169                        let next_counter: Type = parse_quote!(
1170                            <#self_type as #trait_seg>::#next_counter_ident
1171                        );
1172
1173                        let [next_inst, next_counter] = make_type(
1174                            [&next_inst, &next_counter],
1175                            &mut aliases,
1176                            &mut count,
1177                            &self.generics,
1178                        );
1179
1180                        self_type = next_inst;
1181
1182                        let mut bound = self.inst.clone();
1183                        insert_gen_arg(&mut bound, &self.indexes, || {
1184                            Ok(GenericArgument::Type(next_counter))
1185                        })?;
1186
1187                        trait_seg = bound;
1188                    }
1189
1190                    let pre_project = quote::quote! {<#self_type as #trait_seg>};
1191
1192                    let expr = projection.project(&pre_project);
1193
1194                    accessors.push(expr);
1195                }
1196
1197                in_aliases.push(aliases);
1198                in_exprs.push(accessors);
1199                in_borders.push(border.aliases.clone());
1200
1201                // Pick the next argument exactly as the old implementation did.
1202                if next_exists.is_none() {
1203                    if let Some((next, _)) = args_iter.next() {
1204                        self_type = border.node.clone();
1205                        trait_seg = border.inst.clone();
1206
1207                        next_exists = Some(next);
1208                    } else {
1209                        break;
1210                    }
1211                }
1212            }
1213
1214            // SAVE CURRENT BLOCK
1215            aliases.append(&mut in_aliases);
1216            exprs.append(&mut in_exprs);
1217            borders.append(&mut in_borders);
1218
1219            // NO MORE ARGUMENTS
1220            let Some(next) = next_exists else {
1221                break;
1222            };
1223
1224            // MOVE TO NEXT ARGUMENT
1225            //
1226            // Restore the state from the beginning of this block, then construct
1227            // the border corresponding to the argument we just selected.
1228            given = parse_pos_usize(next)?;
1229
1230            self_type = archive_self_type;
1231            trait_seg = archive_trait_seg;
1232
1233            let mut border = BorderInfo {
1234                index: given,
1235                node: self_type.clone(),
1236                inst: trait_seg.clone(),
1237                aliases: Vec::new(),
1238            };
1239            self.take_border(&mut border, &mut count)?;
1240
1241            self_type = border.node.clone();
1242            trait_seg = border.inst.clone();
1243
1244            let Some(hanging_border) = borders.last_mut() else {
1245                return Err(ResolveBugs::HangingBordersNotAvailable {}.into());
1246            };
1247
1248            *hanging_border = border.aliases.clone();
1249        }
1250
1251        Ok(DerivedItems {
1252            ident_checkers,
1253            aliases,
1254            exprs,
1255            borders,
1256        })
1257    }
1258
1259    /// Assembles the derived accessors and identifier checkers into the final
1260    /// dynamic-counter expression.
1261    ///
1262    /// Each identifier checker produces an `Option<usize>`. A successful checker
1263    /// supplies the index used to select the corresponding accessor expression;
1264    /// `None` produces `Error::OutOfRange`.
1265    ///
1266    /// For example, for a single counter:
1267    ///
1268    /// ```text
1269    /// ident_check(...) -> Some(idx)
1270    ///                       |
1271    ///                       ▼
1272    ///                  match idx
1273    ///                  |---0 -> exprs[0]
1274    ///                  |---1 -> exprs[1]
1275    ///                  |---n -> Exhausted
1276    /// ```
1277    ///
1278    /// With multiple counters, the resulting matches are nested, with each
1279    /// identifier checker selecting the next dimension:
1280    ///
1281    /// ```text
1282    /// first identifier
1283    ///        |
1284    ///    counter index
1285    ///        |
1286    /// second identifier
1287    ///        |
1288    ///    counter index
1289    ///        |
1290    ///   final accessor
1291    /// ```
1292    ///
1293    /// The generated border and type aliases are emitted before the selection
1294    /// expression so that all intermediate types required by the accessors are
1295    /// available in the generated item.
1296    ///
1297    /// `OutOfRange` indicates that an identifier does not exist in its counter
1298    /// collection, while `Exhausted` indicates that the identifier exists but
1299    /// that resolved numeric position exceeds the available derived accessors.
1300    fn derive_expr(&self, derives: DerivedItems) -> Result<Expr, TokenStream> {
1301        let DerivedItems {
1302            ident_checkers,
1303            aliases,
1304            exprs,
1305            borders,
1306        } = &derives;
1307
1308        let all_borders = borders.into_iter().flatten();
1309        let all_aliases = aliases.into_iter().flatten();
1310        let prefixes = quote::quote! {
1311            #(#all_borders)*
1312            #(#all_aliases)*
1313        };
1314
1315        let crate_of = Instance::support_crate();
1316
1317        let rev_indexes = self.indexes.ints.iter().rev();
1318
1319        let mut err_indexes = rev_indexes.clone();
1320        let inner_idx = err_indexes.next().unwrap();
1321
1322        let mut matches = Vec::new();
1323        for exprs in exprs.iter() {
1324            let arms = exprs
1325                .into_iter()
1326                .enumerate()
1327                .map(|(i, expr)| {
1328                    quote::quote! {
1329                        #i => {
1330                            Ok({#expr}.into())
1331                        },
1332                    }
1333                })
1334                .collect::<Vec<_>>();
1335
1336            let expr = quote::quote! {
1337                match idx {
1338                    #(#arms)*
1339                    n => {
1340                        Err(#crate_of::Error::Exhausted { depth: n, index: #inner_idx, expect: idx })
1341                    },
1342                }
1343            };
1344            matches.push(expr);
1345        }
1346
1347        let mut derives_iter = ident_checkers.iter();
1348        let first_derive = derives_iter.next().unwrap();
1349        let mut matches_with_last_derive = Vec::new();
1350        for matches in matches.iter() {
1351            let tokens = quote::quote! {
1352                if let Some(idx) = #first_derive {
1353                    #matches
1354                } else {
1355                    Err(#crate_of::Error::OutOfRange {})
1356                }
1357            };
1358            matches_with_last_derive.push(tokens)
1359        }
1360
1361        let Some(second_derive) = derives_iter.next() else {
1362            if matches_with_last_derive.len() > 1 {
1363                return Err(ResolveBugs::OnlyCounterHaveMultiDimensionExprs {}.into());
1364            };
1365            let matched = &matches_with_last_derive[0];
1366            return Ok(parse_quote!(
1367                {
1368                    #prefixes
1369                    #matched
1370                }
1371            ));
1372        };
1373
1374        if matches_with_last_derive.len() <= 1 {
1375            return Err(ResolveBugs::MultiCounterHaveLessThanOneDimensionExprs {}.into());
1376        };
1377
1378        let Some(second_err_idx) = err_indexes.next() else {
1379            return Err(ResolveBugs::MultiCounterButIndexesInsufficient {}.into());
1380        };
1381
1382        let arms = matches_with_last_derive
1383            .into_iter()
1384            .enumerate()
1385            .map(|(i, expr)| {
1386                quote::quote! {
1387                    #i => {
1388                        {#expr}.into()
1389                    },
1390                }
1391            })
1392            .collect::<Vec<_>>();
1393
1394        let final_expr = quote::quote! {
1395            if let Some(idx) = #second_derive {
1396                match idx {
1397                    #(#arms)*
1398                    n => {
1399                        Err(#crate_of::Error::Exhausted { depth: n, index: #second_err_idx, expect: idx })
1400                    }
1401                }
1402            } else {
1403                Err(#crate_of::Error::OutOfRange {})
1404            }
1405        };
1406
1407        if derives_iter.next().is_some() {
1408            return Err(ResolveBugs::TralingIdentCheckersUnnessary {}.into());
1409        }
1410
1411        let finish: Expr = parse_quote!(
1412            {
1413                #prefixes
1414                #final_expr
1415            }
1416        );
1417
1418        Ok(finish)
1419    }
1420}

1422/// Materializes types as generated aliases and returns paths to those aliases.
1423///
1424/// Each input type is assigned a fresh `T{count}` alias, with the original
1425/// generic parameters and where-clause of `generics` attached to the alias.
1426///
1427/// For example:
1428///
1429/// ```text
1430/// input:  [Foo, Bar]
1431/// output aliases:
1432///     type T0<...> = Foo;
1433///     type T1<...> = Bar;
1434/// ```
1435///
1436/// The returned types reference the generated aliases using the generic
1437/// arguments appropriate for use at the alias site. The generated aliases are
1438/// appended to `collect`, and `count` is advanced for each type.
1439fn make_type<const N: usize>(
1440    tys: [&Type; N],
1441    collect: &mut Vec<ItemType>,
1442    count: &mut usize,
1443    generics: &Generics,
1444) -> [Type; N] {
1445    let id = std::array::from_fn(|i| {
1446        let ty = tys[i];
1447        let ident = format_ident!("T{}", *count);
1448
1449        let (decl, ty_use, where_bounds) = generics.split_for_impl();
1450        collect.push(parse_quote!(
1451            #[allow(type_alias_bounds)]
1452            type #ident #decl #where_bounds = #ty;
1453        ));
1454
1455        *count += 1;
1456
1457        parse_quote!(#ident #ty_use)
1458    });
1459
1460    id
1461}

1463/// Builds the complete subscriber call expression from the supplied instance
1464/// type and access arguments.
1465///
1466/// The access arguments are first resolved into [`ExprCallEssentials`], which
1467/// derives the identifier checkers, counter-chain accessors, and required type
1468/// aliases. Those derived items are then assembled into the final expression
1469/// that dynamically resolves the requested instance.
1470fn subscriber_call_expr<'a>(
1471    self_ty: &TypePath,
1472    instance: &mut PathSegment,
1473    projection: &Projection<'a>,
1474    generics: &mut Generics,
1475    access: &AccessArgs,
1476) -> Result<Expr, TokenStream> {
1477    let essence = ExprCallEssentials::get(self_ty, instance, access, generics)?;
1478    let mut count = 0usize;
1479    let derives = essence.derive_items(&mut count, projection)?;
1480    let expr = essence.derive_expr(derives)?;
1481    Ok(expr)
1482}
