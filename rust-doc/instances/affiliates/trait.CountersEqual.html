Expand description

Compares two counter tuples element by element.

The associated Output is B1 when every corresponding counter is equal, and B0 when at least one counter differs.

Each counter position is compared independently with IsEqual, and the resulting boolean values are combined with BitAnd.

Compares two four-counter tuples element by element.

The corresponding counter pairs are compared:

(A0, A1, A2, A3)
(B0, B1, B2, B3)

Their equality results are combined with BitAnd:

A0 == B0
A1 == B1
A2 == B2
A3 == B3

(A0 == B0) AND (A1 == B1) AND (A2 == B2) AND (A3 == B3)

The resulting Output is B1 only when all four counter positions are equal. If any corresponding counter differs, the result is B0.
