Expand description

Dispatches reverse-affiliate resolution from the most significant remaining counter dimension C.

C is the highest-order dimension considered after D has reached zero in a four-counter tuple, or the highest-order dimension in a three-counter tuple (A, B, C). The IsZero parameter selects whether C has reached zero.

When C is non-zero, the default reverse-affiliate step decrements C while preserving all lower dimensions.

When C is zero, the zero-state implementation delegates resolution to ReverseDispatchB, making B the next most significant dimension that can be decremented.

Thus, the zero-state implementation is not itself a terminal case unless B is also exhausted. It transfers reverse resolution to the next dimension in significance order.
