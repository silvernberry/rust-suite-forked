pub trait BoundaryAccess0<SelfTy: ?Sized> {
    type Boundary: CountersGet<U0>;

    const FINAL: u64;

Expand description

Resolves the boundary counter tuple and the final identifier hash for the root identifier sequence.

BoundaryAccess0 is used when there is no preceding identifier sequence. SelfTy alone therefore identifies the contextual instance whose identifiers form the boundary.

FINAL is the hash of the final identifier occurring at this boundary.

For example, if the identifiers at the root boundary are:

a
b
c

FINAL = hash(c)

The associated Boundary type is the complete typenum counter tuple for the boundary and provides access to dimension 0 through CountersGet<U0>.

ⓘ
impl BoundaryAccess0<InstanceType> for Global {
    const FINAL: u64 = { hash_ident(b"c") };
    type Boundary = (U2,);
}

The boundary information can then be recovered through:

ⓘ
<Global as BoundaryAccess0<InstanceType>>::FINAL
<Global as BoundaryAccess0<InstanceType>>::Boundary
