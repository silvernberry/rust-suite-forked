Expand description

Dispatches reverse-affiliate resolution for the least significant remaining counter dimension A.

A is the final dimension reached after every more significant dimension has been exhausted. The IsZero parameter selects whether A has reached zero.

When A is non-zero, the default reverse-affiliate step decrements A.

When A is zero, the zero-state implementation is the terminal default: no further reverse-affiliate step is possible, so the counter tuple is returned unchanged.

ReverseDispatchA therefore provides the termination point of the dimension-by-dimension reverse traversal.
