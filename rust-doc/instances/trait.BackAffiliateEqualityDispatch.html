Expand description

Dispatches back-affiliate resolution according to whether ReverseNext is equal to Current.

This dispatch is reached only after Current has been determined not to be the global minimum.

When CountersEqual is true, ReverseNext identifies the current position’s reverse successor, so Reverse is selected.

When CountersEqual is false, ReverseNext does not equal Current, so the back-affiliate resolves to ReverseFloor.
