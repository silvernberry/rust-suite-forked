) -> GenericArray<GenericArray<GenericArray<Option<T>, NC>, NB>, NA>
Expand description

Expands a three-dimensional historical collection to the new cardinalities and records a value at the specified three-dimensional coordinate.

Existing entries are preserved at their original coordinates. Coordinates introduced by any dimension are initialized to None, after which value is written at (ia, ib, ic).

The output dimensions must not be smaller than their corresponding input dimensions, and every supplied coordinate must lie within the output shape:

NA >= OA
NB >= OB
NC >= OC

ia < NA
ib < NB
ic < NC

For example:

Old:
[
    [
        [Some(A), Some(B)],
        [Some(C), None],
    ],
]

Expanded:
[
    [
        [Some(A), Some(B), None],
        [Some(C), None,    None],
    ],
]

(ia, ib, ic) = (0, 1, 1)
value = Some(D)

Result:
[
    [
        [Some(A), Some(B), None],
        [Some(C), Some(D), None],
    ],
]

This function is const so historical collection expansion can be evaluated during compile-time processing.
