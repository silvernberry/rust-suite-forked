Expand description

Resolves the back-affiliate counter tuple.

The resolution is performed in two stages. First, Current is checked against the global minimum. If it is the global minimum, no back-affiliate exists and Current is retained.

Otherwise, ReverseNext is compared with Current. When they are equal, Reverse is selected; otherwise ReverseFloor is selected.

Inputs:

Current
Reverse
ReverseNext
ReverseFloor

Resolution:

Current == GlobalMin
    => Current

Current != GlobalMin
    => ReverseNext == Current

ReverseNext == Current
    => Reverse

ReverseNext != Current
    => ReverseFloor

The associated Output type is therefore the counter tuple determined by these two compile-time decisions.

Entry point for back-affiliate resolution.

The resolution first determines whether Current is the global minimum. If it is, Current is returned unchanged.

Otherwise, Current is compared with ReverseNext. When they are equal, Reverse is selected; when they differ, ReverseFloor is selected.

Example:

Current      = (U0, U0, U5)
Reverse      = (U0, U0, U4)
ReverseNext  = (U0, U0, U5)
ReverseFloor = (U0, U0, U0)

Current != GlobalMin
ReverseNext == Current

Output = Reverse

Example:

Current      = (U0, U0, U7)
Reverse      = (U0, U0, U6)
ReverseNext  = (U0, U0, U9)
ReverseFloor = (U0, U0, U0)

Current != GlobalMin
ReverseNext != Current

Output = ReverseFloor

Example:

Current = GlobalMin

Output = Current

BackAffiliate provides the public entry point while BackAffiliateGlobalMinDispatch and BackAffiliateEqualityDispatch perform the individual compile-time decisions.
