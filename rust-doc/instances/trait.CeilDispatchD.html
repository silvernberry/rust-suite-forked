Expand description

Dispatches ceil resolution from the most significant counter dimension D.

D is the highest-order dimension in a four-counter tuple (A, B, C, D). The IsZero parameter determines whether D has reached zero.

When D is non-zero, the default implementation resolves the ceil value by setting D to zero while preserving all lower dimensions.

When D is zero, the zero-state implementation delegates to CeilDispatchC, making C the next most significant dimension that can be resolved.

The zero-state implementation therefore represents a dimension boundary: the current dimension has already reached its ceil boundary, so resolution continues with the next lower dimension.

The same dispatch trait is used for tuples with fewer counters by treating the highest available dimension as the current most significant dimension.
