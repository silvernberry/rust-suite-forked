pub trait Affiliation { }
Expand description

Identifies a type-level counter affiliation operation.

An affiliation describes how a counter tuple is related to another position in its counter space. Concrete affiliation marker types select the operation performed by DirectAffiliate.

Dyn Compatibility§

This trait is dyn compatible.
