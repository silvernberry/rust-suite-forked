Expand description

Derives the collection length for one dimension from a tuple of counters.

Counters represents the counters of all dimensions, with each counter stored at the position corresponding to its dimension:

Counters = (U0, U1, U2)
            |   |   |
            |   |   |--- dimension 2 counter
            |   |------- dimension 1 counter
            |----------- dimension 0 counter

Index selects one counter from this tuple. The selected counter represents the last zero-based position occupied in that dimension. Therefore, its collection length is one greater than the counter:

selected counter = N
collection length = N + 1

For example, given:

Counters = (U0, U1, U2)

the collection length for each dimension is:

Index 0:
    counter = U0
    length  = U0 + U1 = U1

Index 1:
    counter = U1
    length  = U1 + U1 = U2

Index 2:
    counter = U2
    length  = U2 + U1 = U3

In other words, CountersCollectionLen<Index> performs two type-level operations:

Counters
    | CountersGet<Index>
counter at Index
    | + U1
collection length

For a larger counter tuple:

Counters = (U2, U4, U1)

the dimensions have the following collection lengths:

dimension 0    counter U2    length U3
dimension 1    counter U4    length U5
dimension 2    counter U1    length U2

The resulting Output is a type-level Unsigned value and can therefore be used as the cardinality of a compile-time collection such as GenericArray.
