Expand description

Resolves the boundary counter tuple and the final identifier hash for a boundary identified by a two-element sequence of compile-time identifier hashes.

A and B identify the preceding identifier sequence. The boundary consists of the identifiers that immediately extend that sequence.

For example, given:

a, b, c
a, b, k

the boundary identified by a, b has:

INITIAL = hash(c)
FINAL   = hash(k)

FINAL therefore identifies the last identifier occurring at the boundary, while the associated Boundary type contains the complete typenum counter tuple for the a, b prefix.

Each tuple position corresponds to the same dimension position in the preceding identifier sequence and can be accessed through the corresponding CountersGet implementation.
