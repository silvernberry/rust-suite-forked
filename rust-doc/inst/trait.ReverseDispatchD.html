Expand description

Dispatches reverse-affiliate resolution from the most significant counter dimension D.

D is the highest-order dimension in a four-counter tuple (A, B, C, D). The IsZero parameter selects whether that dimension has reached zero.

When D is non-zero, the default reverse-affiliate step decrements D while preserving all lower dimensions.

When D is zero, the zero-state implementation delegates resolution to ReverseDispatchC, making C the next most significant dimension that can be decremented.

The zero-state implementation therefore acts as the recursive boundary between dimensions: a dimension is exhausted before reverse resolution proceeds to the next lower dimension.
