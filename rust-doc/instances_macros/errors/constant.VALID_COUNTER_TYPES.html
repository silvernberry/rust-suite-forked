Allowed primitive integer types for trait const-generic instance counters.

In this crate, “counters” refer to the const generics of a trait that represent instance-selection positions.

Example:

ⓘ
trait Example<const A: usize, const B: usize> {}

Here, A and B are instance counters.

Only unsigned integer primitives are supported because instance selection relies on deterministic positional indexing and positive, non-negative counter semantics during macro expansion.
