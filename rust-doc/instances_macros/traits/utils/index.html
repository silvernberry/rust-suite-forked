Shared extraction utilities and validation helpers used throughout the instance-trait proc-macro pipeline.

It also includes reusable validation macros for associated types, associated constants, and generated where predicates.

Macros§

validate_trait_const 🔒
Validates a single associated constant against an expected identifier, type, generic configuration, and optional default expression.
validate_trait_consts 🔒
Validates a collection of associated constants against an expected associated-constant contract.
validate_trait_type 🔒
Validates a single associated type against an expected identifier, generic-parameter configuration, and optional trait-bound contract.
validate_trait_types 🔒
Validates a collection of associated types against an expected associated-type contract.
validate_where_predicate 🔒
Validates a where predicate by matching a bounded type and verifying that the expected trait bound is present.
