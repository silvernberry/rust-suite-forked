Expand description

Defines transformation of an existing value (Type) in place.

Unlike extension (which derives and inserts new data), transformation operates directly on the target, modifying or projecting its internal representation. See Extension for extension-based workflows.

Self acts as contextual or extracted data used to drive how the transformation is applied.

Context provides optional external state, configuration, or borrowed supporting data used during transformation.

Since Self is typically owned ('static), Context is commonly used to provide temporary borrowed data required during derivation or validation.

Provides two execution paths:

  • Self::checked_transform: applies transformation with post-validation
  • Self::unchecked_transform: applies transformation with minimal checks

This is typically used for rewriting, normalizing, or updating a structure without introducing new elements via insertion.

fn raw_transform( &self, transform: &mut Type, context: &Context, ) -> Result<(), TokenStream>

Performs the core transformation logic.

Mutates the target in place using Self as context, updating its internal representation.

Source

fn validate_transform( &self, transform: &Type, context: Option<&Context>, ) -> Result<(), TokenStream>

Validates the transformed state.

context and type are optional so this validation hook may be reused independently from the checked extraction pipeline, such as:

  • standalone tests,
  • partial pipeline execution,
  • manual validation,
  • or external validation utilities.

fn checked_transform( &self, transform: &mut Type, context: &Context, ) -> Result<(), TokenStream>

Performs transformation with full validation.

fn unchecked_transform( &self, transform: &mut Type, context: &Context, ) -> Result<(), TokenStream>

Performs transformation with minimal validation.

Applies the transformation without validating the result.

Source

fn validate_context(&self, _context: &Context) -> Result<(), TokenStream>

Validates the transformation context.

Default implementation performs no validation.

Source

fn validate_type(&self, _type: &Type) -> Result<(), TokenStream>

Validates the target before transformation.

Override to ensure the target is in a valid state prior to mutation.

Default implementation performs no validation.
