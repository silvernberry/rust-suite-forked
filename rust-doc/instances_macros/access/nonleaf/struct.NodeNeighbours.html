Struct NodeNeighbours 

Source 
struct NodeNeighbours {
    global: TypePath,
    initial: TypePath,
    final_: TypePath,
    node: TypePath,
}
Expand description

Describes the generated type representations associated with an instance node and its position within the instance hierarchy (see crate::node).

Each representation corresponds to a distinct role of the same instance node:

  • global - the generated global representation of the node (GLOBAL_NODE);
  • initial - the representation used as the initial boundary of the node (INITIAL_NODE);
  • final_ - the representation used as the final boundary of the node (FINAL_NODE); and
  • node - the representation identifying the node itself.

These representations are derived together because the instance-node transformation needs to relate the node’s global, boundary, and concrete forms when constructing the generated instance hierarchy.

The four types therefore describe the same logical instance node from different positions in the generated type-level hierarchy.

fn get_node_path(node: &TypePath) -> Result<Self, TokenStream>

Derives the generated type paths associated with an instance node.

The supplied node represents the original instance node. Its final path segment identifies the node, and that identifier is used to derive the corresponding generated representations:

Node
|---NodeInitial
|---NodeFinal
|---NodeGlobal

The original path is preserved as node, while its final segment is replaced with the generated InstanceNode variants for initial, final_, and global.

All other segments of the original path, including its generic arguments and qualification, are preserved unchanged.

Source

fn get_node_instances( &self, inst: &mut PathSegment, indexes: &IntList, ) -> Result<(PathSegment, PathSegment), TokenStream>

Derives the initial and final instance paths for a node.

The supplied inst contains the instance path whose node type argument identifies the current node. The node’s generic arguments are first removed at the positions specified by indexes, and two copies of the resulting path are created.

The first copy receives the generated initial node type, while the second receives the generated final_ node type:

inst<..., Node, ...>
      |
      |---initial -> inst<..., NodeInitial, ...>
      |---final   -> inst<..., NodeFinal, ...>

Only the node type argument at first index-value of indexes is replaced; the surrounding path structure is preserved.

The returned paths represent the initial and final instance boundaries of the node and are used when constructing the corresponding instance hierarchy representations.

fn prefix_bound( &self, generics: &mut Generics, indexes: &IntList, prefixes: &BStringList, ) -> Result<(), TokenStream>

Adds a where-predicate that confirms the supplied prefixes through OnSetAccess on the node’s global representation.

For example, prefixes such as b"x", b"y" are resolved through OnSetAccess to produce the corresponding access bound, which is then added as a constraint on the generics used throughout all declarations:

NodeInitial: <OnSetAccess for GlobalNode using [x, y]>

This ensures that the generated initial node satisfies the requested prefix access.
