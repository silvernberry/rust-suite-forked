instances_macros::node

Source
Expand description

Shared declarative infrastructure for generated instance node transformations.

This module declares the common transformation framework shared by every specialized instance node on both the declaration (trait) and implementation (impl) sides.

It provides:

  • Shared preparation and validation pipelines (TraitNodeSegment, ImplNodeSegment).
  • Mutable transformation state and helper APIs for generated companion nodes (TraitNodeState, ImplNodeState).

Rather than implementing the semantics of individual instance nodes, this module declares the common lifecycle, generated companion node model, and mutation interfaces used by all specialized node transformations.
