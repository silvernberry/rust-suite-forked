Deterministic suffix for the generated initial range companion associated type.

Range-based instance nodes generate a neighbouring initial companion type representing the beginning of the selected instance range.

Unlike the original instance associated type, the initial companion may depend on other generated companion types such as the instance global (GLOBAL_NODE) and twin (TWIN_NODE). This allows specialized instance nodes to contribute supplementary bounds without coupling them to the original instance declaration.

The initial companion exposes the beginning of the selected range through an associated type, allowing the original instance associated type to recover the initial instance path.

Example:

Traverse:
    Leaf ---> Branch

Instance:
    type Account;

Generated:
    type AccountInitial: CounterAccess

    Account:
        type Initial =
            <Self::AccountInitial as InitialAssocAccess>::Initial;

Together with FINAL_NODE, the initial companion encodes the bounds of a selected instance range while the publisher implementation supplies the concrete instance associated type.
