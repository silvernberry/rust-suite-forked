pub fn append_placeholder_args(
    bounds: &mut Punctuated<TypeParamBound, Plus>,
    path: &Punctuated<Ident, PathSep>,
    bound: &InstanceModel,
    push_args: bool,
) -> Result<IntList, TokenStream>
Expand description

A trait-bound is matched against path. The matching trait bound is removed, its instance arguments are appended after lifetime arguments, and the transformed bound is inserted at the beginning of the bounds list.

If push_args is true, each instance parameter position receives a placeholder const argument (0). If false, only the positions are calculated and returned.

Before:

ⓘ
T: Crypto::Hasher + Send

After with bound = (Module, Function) and push_args = true:

ⓘ
T: Crypto::Hasher<0, 0> + Send

The returned IntList contains the generic argument positions of the inserted instance counters.
